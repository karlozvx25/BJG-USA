# Sistema visual BJG USA

Concepto: certeza a distancia. Idea rectora: México sigue cerca. La narrativa conecta identificación, claridad, proceso, personas y acción. CTA consistente: «Cuéntanos tu caso».

| Token         | Valor   | Uso                              |
| ------------- | ------- | -------------------------------- |
| Navy          | #0B1F33 | Hero, navegación, portal, footer |
| Deep blue     | #17395C | Secciones de confianza, hover    |
| Burgundy      | #9D2C35 | Acción principal                 |
| Heritage gold | #B89A62 | Legado y conexión sobre oscuro   |
| Ivory         | #F6F3ED | Fondos de lectura                |

Inter para interfaz; DM Serif Display para titulares. Ambas servidas localmente con Fontsource. Titulares fluidos; cuerpo entre 14–16 px en la composición principal. Textos auxiliares pequeños reservados a etiquetas. Dorado oscuro #735c32 para etiquetas sobre marfil.

Contenedor máximo 1240 px, bordes finos, radios 5–10 px, sombras discretas. Mobile: columnas reducidas, tarjetas de equipo horizontales y CTA inferior persistente. Menú móvil desplegable. Foco visible, enlace para saltar al contenido, etiquetas de formulario, validación nativa, reduced-motion, iconos acompañados por texto.

Connection Line: puntos y una línea sutil que conectan Estados Unidos y México. Abstracciones geométricas originales en CSS, sin stock jurídico. Sustituir Art por imágenes reales con alt, dimensiones explícitas, lazy loading fuera del hero y versiones WebP/AVIF. Hero 4:5 aproximado; retratos 3:4; legado horizontal. Usar luz natural y personas reales con autorización.

No se muestran cifras no verificadas ni testimonios ficticios. Los espacios pendientes se identifican de forma explícita.
